# 乐谱格式

`make.py --score xxx.json` 会跳过内置的夜曲，按这份 JSON 生成音符。适合让模型每次现写一首。

## 最小示例

```json
{
  "title": "小 圆 舞",
  "titleEn": "VALSE IN D MINOR",
  "bpm": 96,
  "key": "D",
  "mode": "minor",
  "meter": [3, 4],
  "pattern": "waltz",
  "chords": ["Dm", "Gm", "A", "Dm"],
  "melody": [
    [0, 0, 1.5, 4, 0, 0.78],
    [0, 1.5, 1, 2, 1, 0.72]
  ]
}
```

## 字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `chords` | 是 | 每小节一个和弦名，`Am` `F` `C` `G7` `Bdim` `Caug` `Dmaj7` 都认 |
| `melody` | 是 | `[小节, 拍, 时值(拍), 音级, 八度, 力度]` |
| `key` / `mode` | 否 | 默认 `A` / `minor`；mode 支持 `minor` `major` `harmonic_minor` `dorian` |
| `meter` | 否 | 默认 `[4,4]`；`[3,4]` 是圆舞曲 |
| `pattern` | 否 | 左手织体，见[织体](#织体)一节。原四种 `nocturne` `waltz` `block` `arpeggio`，新增六种 `pulse` `ostinato` `counter` `drone` `broken` `waltz2` |
| `bassLine` | 否 | 每小节一个低音音名（`["D2","C2","B1"]`），覆盖和弦根音，用来写级进低音线条。比和弦根音短时循环末尾值 |
| `motif` | 否 | 动机的音级偏移（`[0,5,4,2]`），供 `critic2` 检测原形/倒影/逆行/逆行倒影四种形态 |
| `bpm` | 否 | 默认 72 |
| `title` / `titleEn` / `subtitle` | 否 | 片头文案，不填则用默认 |
| `shimmer` | 否 | 默认 `true`，给力度 ≥ 0.86 的旋律音叠一层高八度 |
| `velocity` | 否 | 整体力度缩放，默认 1.0 |
| `sections` | 否 | 分段配置：`[{"name":"A","bars":[0,8],"pattern":"nocturne","dynamic":0.82}]`，`bars` 左闭右开 |
| `tempo` | 否 | `{"map":[[0,60],[8,64],[16,58]],"rit":{"bar":22,"barTo":24,"factor":0.8}}`，按小节线性插值，`rit` 是收尾渐慢 |
| `voicing` | 否 | `lead`（默认）取离上一小节最近的转位，有声部进行；`close` 为原位堆叠；`color` 保持根音在底、把七音/九音放到上方（五音省略），扩展和弦靠它才不糊 |
| `patternVar` | 否 | 1 表示每 3 小节轮换一次琶音音型，避免整段一个循环 |
| `tail` | 否 | 最后一个音之后的余响秒数，默认 0.6；建议 5–7，给片尾卡留出时间 |

## 音级怎么算

`deg` 是音阶级数，**不是半音**：

- D 小调（D E F G A Bb C）→ `deg` 0=D 1=E 2=F 3=G 4=A 5=Bb 6=C 7=D(高八度)
- `oct` 相对中央 C：`oct=0` 的 `deg=0` 是 D4（MIDI 62），`oct=1` 是 D5

音域建议 `oct` 0–1、`deg` 0–7，即大致 C4–C6。

第 7 个元素可选，是**半音偏移**：`[11, 1, .5, 4, 0, .82, -1]` 表示第 4 音级降半音。`acc ≠ 0` 的音不会被吸附到和弦音，用来写导音、降六、减五这类变化音。

## 织体

低音落在哪一拍，是听感上"有没有律动"的分水岭。旧的四种织体低音全在第 1 拍、时值整小节，连续听会像同一首。

| pattern | 低音位置 | 特征 | 适合 BPM |
| --- | --- | --- | --- |
| `nocturne` | 第 1 拍，整小节 | 六等分琶音（记谱为三连音） | 60–76 |
| `arpeggio` | 第 1 拍 | 十六分琶音 | 70–96 |
| `waltz` | 第 1 拍 | 低音 + 两拍和弦 | 90–132 |
| `block` | 第 1 拍 | 持续柱式和弦 | 50–70 |
| `pulse` | **每拍** | 四分柱式推进，适合推上去的段落 | 80–120 |
| `ostinato` | **第 1 拍 + 第 2.5 拍** | 有棱角的八分固定音型，重音在反常规位置 | 100–130 |
| `counter` | **第 1 拍 + 第 3 拍** | 左手二声部：二分低音 + 弱拍中声部应答 | 66–92 |
| `drone` | 第 1 拍，整小节 | 持续根音与五度，上方稀疏点染 | 40–66 |
| `broken` | **弱起 0.5 拍 + 第 2.75 拍** | 八分分解，反拍略重 | 72–104 |
| `waltz2` | **第 3 拍** | 反转圆舞曲，重心后移 | 66–96 |

## 和声记号

`parse_chord` 现在按音程表解析，不再只有三和弦：

| 类别 | 记号 |
| --- | --- |
| 三和弦 | `C` `Cm` `Cdim` `Caug` `C5` |
| 七和弦 | `Cmaj7` `Cm7` `C7` `Cm7b5` `Cdim7` `CmMaj7` |
| 六/九/十一/十三 | `C6` `Cm6` `C6/9` `Cm6/9` `Cm9` `Cmaj9` `C9` `C11` `C13` |
| 挂留 | `Csus2` `Csus4` `C7sus4` |
| 加音 | `Cadd9` `Cmadd9` |
| 变化音 | `C7b9` `C7#9` `C7#11` `Cmaj7#11` |
| 转位 | `C/E` `Bb/D` |

只有 `/` 后面是音名才算转位，`C6/9` 的 `/9` 属于和弦品质。

色彩和声常用的四个来源：

- **降 II（拿波里）**：小调里 `Db9` → `Cm9`，比 `Dm7b5` 更亮也更突然
- **导减七**：`Bdim7` → `Cm`，四个音都在往主音挤
- **副属**：`C7/E` → `Fm`（V/iv），`E` 是临时导音，一瞬间离开调
- **利底亚**：持续音上挂 `Cmaj7#11`，升四度把调式照亮

多利亚则天生适合 `Dm9` 配 `C6/9`、`Bm7b5`——大六度不用改就是色彩。

## 作曲约定（照这个写，下限不会难听）

1. **先定进行再写旋律**。安全的小调进行：`i–VI–III–VII`、`i–iv–V–i`、`i–VI–iv–V`、`i–VII–VI–V`。大调：`I–V–vi–IV`、`I–vi–IV–V`。想在和声上更进一步，见上面四个色彩来源。
2. **线条要有方向**，不是"以级进为主"。级进是黏合剂，跳进是标点：一个乐句里应该有一次四度以上的跳进，跳进之后用反方向的级进解决。全曲大跳（≥5 半音）占比 **10%–35%**，低于 10% 就是平淡。也不要每句都从主音起、都在主音落。
3. **动机要有形状**。3–4 个音，含一次 3–5 级的跳进，节奏有长短对比（比如短-短-长）。写下 `motif` 字段，用 `tools/motif.py` 的 `shift / invert / retro / retro_invert / augment` 发展，全曲至少出现 **3 种形态**。只把动机移高一级不算发展。
4. **强拍落在和弦音上**。没把握就随便写，loader 会把整数拍上的音吸附到当前小节和弦音（±6 半音内取最近）。
5. **一句的最后一个音要长**（2–3 拍），落在主音或三音上，留呼吸。
6. **结尾**：最后 2 小节用 `i`（或 `I`），旋律落在 `deg=0`，时值拉长到 3–4 拍。
7. **长度** 12–28 小节；4/4 拍每小节旋律 3–6 个音，3/4 拍 2–4 个音，别塞满。
8. **BPM 与音型匹配**：查[织体](#织体)表最后一列。
9. **写 `"tail": 6`**。末尾留 6 秒余响，片尾「曲终」才不会压在最后几个音符上。
10. **分段要换织体**，不是只换力度。至少 A（陈述）、B（对比）、A'（回归）、Coda，全曲 **≥3 种 pattern**。同一种织体连续超过 10 小节就该换。
11. **力度要有落差**：整曲力度极差至少 0.35。高潮段 `dynamic` 要到 1.0，Coda 要真的落到 0.45–0.55，中间不要一路 0.8 平推。
12. **动机要变形**：一个 3–4 音的动机在全曲出现 3–8 次，其中至少一次倒影、一次逆行或扩大。每次原样重复都在消耗听众的注意力。
13. **收尾渐慢**：`tempo.rit` 的 `factor` 取 0.75–0.85，从倒数第 2–3 小节开始。
14. **和声要有色彩**：非三和弦（七/九/挂留/加音/变化音）占比 ≥35%，离调（降 II、导七、副属、利底亚升四）占比 6%–35%。全是调内三和弦 = 没有戏剧张力。
15. **低音要独立**：用 `bassLine` 写一条线（级进下行最常见），低音不要永远落在第 1 拍、时值整小节。低音拍位至少 2 种。

> 这 15 条是 2026-11 修订版。旧版第 2 条写的是"以级进为主，三四度跳进每两小节最多一次"，第 12 条写的是"移高一级"——这两条直接生产了八首听起来一样的曲子，已删除。

## 打分

写完先跑评审器，别直接渲染：

```bash
python3 pipeline/critic2.py --history scores/ cands/*.json --out cands/best.json
```

`critic2` 按 12 项打分：动机辨识（音程 + 时值联合重复）、**动机变形**（P/I/R/RI 形态数）、音程多样、音域、力度层次、**织体变化**、**低音独立**（拍位与音高变化）、**和声色彩**（品质种类与占比）、**离调密度**、段落密度对比、终止式、与旧作的新颖度。满分 100。

`critic.py`（v1）只测旋律，和声、织体、低音、节奏四项权重为 0，且把"级进率"设成 0.20 权重——它会给八首同质化的曲子打 82–100 分。**新曲用 `critic2`，`critic` 只用于复核历史分数。**

参考：2026-11-14 ~ 11-21 那八首在 `critic2` 下是 34.8–50.7 分；11-21 重写的三首是 97.0–98.9。

低于 80 分建议重写，不要拿它占坑。

## 想更自由

- 换 `mode` 到 `dorian` 会得到明亮一点的小调，`harmonic_minor` 有升七级的古典味。
- `pattern` 换 `block` 适合慢速、和声厚的段落；`arpeggio` 适合流动感。
- 需要副旋律时，可以在 `melody` 里同一拍写两个音（不同 `oct`），会自动叠成双音。

## 检查

跑 `--preview 4` 先听 4 秒、看一眼静帧，再渲全片。若音符数量为 0 或时长异常，多半是 `chords` 为空或 `melody` 的 `bar` 越界。
