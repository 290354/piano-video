# 乐谱格式

`make.py --score xxx.json` 会跳过内置的夜曲，按这份 JSON 生成音符。适合让模型每次现写一首。

## 最小示例

```json
{
  "title": "小 圆 舞",
  "titleEn": "VALSE IN D MINOR",
  "bpm": 96,
  "key": "D",
  "mode": "minor",
  "meter": [3, 4],
  "pattern": "waltz",
  "chords": ["Dm", "Gm", "A", "Dm"],
  "melody": [
    [0, 0, 1.5, 4, 0, 0.78],
    [0, 1.5, 1, 2, 1, 0.72]
  ]
}
```

## 字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `chords` | 是 | 每小节一个和弦名，`Am` `F` `C` `G7` `Bdim` `Caug` `Dmaj7` 都认 |
| `melody` | 是 | `[小节, 拍, 时值(拍), 音级, 八度, 力度]` |
| `key` / `mode` | 否 | 默认 `A` / `minor`；mode 支持 `minor` `major` `harmonic_minor` `dorian` |
| `meter` | 否 | 默认 `[4,4]`；`[3,4]` 是圆舞曲 |
| `pattern` | 否 | 左手音型：`nocturne`（八分琶音）、`waltz`（低音+和弦）、`block`（柱式）、`arpeggio`（十六分） |
| `bpm` | 否 | 默认 72 |
| `title` / `titleEn` / `subtitle` | 否 | 片头文案，不填则用默认 |
| `shimmer` | 否 | 默认 `true`，给力度 ≥ 0.86 的旋律音叠一层高八度 |
| `velocity` | 否 | 整体力度缩放，默认 1.0 |
| `sections` | 否 | 分段配置：`[{"name":"A","bars":[0,8],"pattern":"nocturne","dynamic":0.82}]`，`bars` 左闭右开 |
| `tempo` | 否 | `{"map":[[0,60],[8,64],[16,58]],"rit":{"bar":22,"barTo":24,"factor":0.8}}`，按小节线性插值，`rit` 是收尾渐慢 |
| `voicing` | 否 | `lead`（默认）取离上一小节最近的转位，有声部进行；`close` 为原位堆叠 |
| `patternVar` | 否 | 1 表示每 3 小节轮换一次琶音音型，避免整段一个循环 |
| `tail` | 否 | 最后一个音之后的余响秒数，默认 0.6；建议 5–7，给片尾卡留出时间 |

## 音级怎么算

`deg` 是音阶级数，**不是半音**：

- D 小调（D E F G A Bb C）→ `deg` 0=D 1=E 2=F 3=G 4=A 5=Bb 6=C 7=D(高八度)
- `oct` 相对中央 C：`oct=0` 的 `deg=0` 是 D4（MIDI 62），`oct=1` 是 D5

音域建议 `oct` 0–1、`deg` 0–7，即大致 C4–C6。

## 作曲约定（照这个写，下限不会难听）

1. **先定进行再写旋律**。安全的小调进行：`i–VI–III–VII`、`i–iv–V–i`、`i–VI–iv–V`、`i–VII–VI–V`。大调：`I–V–vi–IV`、`I–vi–IV–V`。
2. **旋律以级进为主**：相邻音差 1–2 级，三四度跳进（3–4 级）每两小节最多一次，避免连续同向跳进。
3. **每 2 小节一个动机**，后面重复时改尾巴或移高/移低一级，不要每小节都换新材料。
4. **强拍落在和弦音上**。没把握就随便写，loader 会把整数拍上的音吸附到当前小节和弦音（±6 半音内取最近）。
5. **一句的最后一个音要长**（2–3 拍），落在主音或三音上，留呼吸。
6. **结尾**：最后 2 小节用 `i`（或 `I`），旋律落在 `deg=0`，时值拉长到 3–4 拍。
7. **长度** 12–24 小节；4/4 拍每小节旋律 3–6 个音，3/4 拍 2–4 个音，别塞满。
8. **BPM 与音型匹配**：`nocturne` 60–76，`waltz` 90–132，`block` 50–70，`arpeggio` 70–96。
9. **写 `"tail": 6`**。末尾留 6 秒余响，片尾「曲终」才不会压在最后几个音符上。
10. **必须分段**：至少 A（陈述）、B（对比）、A'（回归）、Coda（收尾）。各段换织体或换力度，否则全曲是一个密度，听两小节就腻。
11. **力度要有落差**：整曲力度极差至少 0.25，靠 `sections[].dynamic` 制造 3–5 dB 的段落差。
12. **动机要回来**：一个 3–4 音的动机在全曲出现 3–6 次，每次换个尾巴或移高一级，不要每次都是新材料。
13. **收尾渐慢**：`tempo.rit` 的 `factor` 取 0.75–0.85，从倒数第 2–3 小节开始。

## 打分

写完先跑评审器，别直接渲染：

```bash
python3 pipeline/critic.py --history scores/ cands/*.json --out cands/best.json
```

它按 8 项指标打分（级进率、音域、音高多样性、力度层次、段落密度对比、动机重复、对旧作的新颖度、终止式），满分 100。低于 80 分建议重写，不要拿它占坑。

## 想更自由

- 换 `mode` 到 `dorian` 会得到明亮一点的小调，`harmonic_minor` 有升七级的古典味。
- `pattern` 换 `block` 适合慢速、和声厚的段落；`arpeggio` 适合流动感。
- 需要副旋律时，可以在 `melody` 里同一拍写两个音（不同 `oct`），会自动叠成双音。

## 检查

跑 `--preview 4` 先听 4 秒、看一眼静帧，再渲全片。若音符数量为 0 或时长异常，多半是 `chords` 为空或 `melody` 的 `bar` 越界。
